# 02 回帰とモデルの選び方

文章・数式・図を読み、直線や点、モデルの設定を変えて、予測・誤差・汎化・モデル選択を学びます。本文は [notebook.py](notebook.py) にあります。コードの入力や書き換えは不要です。

約55分が目安です（試読による実測は未了）。

## 開き方

[環境の準備](../SETUP.md)を済ませ、ターミナルで教材ルート（`README.md` と `SETUP.md` がある `b3-ml-bootcamp` フォルダ）へ移動します。`02-regression` の中では実行しません。

全章共通の入口を開きます。VS Codeのターミナルでも同じコマンドです。

```sh
uv run python app.py
```

教材一覧、または左上の **☰** メニューから「02 回帰とモデルの選び方」を選びます。すでに入口を開いている場合は、サイドバーで章を選ぶだけです。

ブラウザが自動で開かない場合は、ターミナルに表示されたURLを開いてください。`run`は教材をアプリとして表示するモードです。本文・図・スライダー・ボタンが表示され、操作すると再計算されます。本文中の「計算の中身を見る」も開けます。

`edit`で開いてコードの断片や黄色いセル枠が見えている場合は、その起動元のターミナルで `Ctrl+C` を押し、上のコマンドで開き直してください。編集画面では、コードを折りたたんでもセルの境界が残ります。また、起動時の実行設定によっては、全セルを実行するまで図や操作結果が更新されません。

教材のソースを編集するときだけ、`uv run marimo edit 02-regression/notebook.py` を使います。その場合は全セルを実行し、変更後の自動実行を有効にして動作を確認してください。

終了は起動したターミナルで `Ctrl+C`、再開は同じ場所で同じ起動コマンドです。最終評価は再起動しても同じtestを使うため、一度見たtestを新しい評価用データとは呼びません。

## 試せること

- 傾き・切片を変え、操作部の式、残差、図内のMSEを確かめる。最小二乗解へのボタンは入力値も切り替える。
- 6人の入力・正解データで、特徴量1個／2個の予測とMSEを比較する。「学習時間だけ」では練習回数の項と操作部を隠す。最小二乗法で重みを求め、手で変えた結果と比較する。
- 過学習は固定した1・3・9次の曲線と、1〜9次の訓練・検証MSEを見比べる。操作せずに当てはまりと汎化の違いを確認できる。
- 訓練10点を使い、3次→9次の過学習→正則化→強すぎる正則化の4段階で、曲線とMSEの変化を比べる。
- 「λを変えて、次数ごとのMSEを見る（任意）」では、次数1〜9それぞれの訓練・検証MSEを同じグラフで比較する。各点の次数とMSEはカーソルを合わせて確認できる。
- 最終評価欄で次数・λを選ぶたびに係数を自動で学習し直し、係数入りの式・曲線・訓練／検証MSEを確認する。λは0と10⁻¹⁴〜10⁻⁴の対数間隔で、小さな正則化の効果を比べる。評価ボタンでモデルを固定し、テスト点とテストMSEを図に追加する。

本文・計算・SVG生成はすべて [notebook.py](notebook.py) にまとめています。見た目は [notebook.css](notebook.css) で整えています。別のPythonファイルは不要です。外部データの取得やGPUは不要です。機械学習帳の読書は任意です。
