# 02 回帰とモデルの選び方

文章と図を読み、いくつかの図を操作しながら、予測・損失・学習・汎化・モデル選択を学びます。「（任意）」と付いた折りたたみは飛ばしてかまいません。途中に一か所、数行のコードを書き換えて試せる欄があります。

## 開き方

[環境の準備](../SETUP.md)を済ませ、ターミナルで教材ルート（`README.md` と `SETUP.md` がある `ml-bootcamp` フォルダ）へ移動します。`02-regression` の中では実行しません。

全章共通の入口を開きます。VS Codeのターミナルでも同じコマンドです。

```sh
uv run python app.py
```

教材一覧、または左上の **☰** メニューから「02 回帰とモデルの選び方」を選びます。すでに入口を開いている場合は、サイドバーで章を選ぶだけです。

ブラウザが自動で開かない場合は、ターミナルに表示されたURLを開いてください。`run`は教材をアプリとして表示するモードです。本文・図・ボタンが表示され、操作すると図が変わります。

`edit`で開いてコードの断片や黄色いセル枠が見えている場合は、その起動元のターミナルで `Ctrl+C` を押し、上のコマンドで開き直してください。編集画面では、コードを折りたたんでもセルの境界が残ります。また、起動時の実行設定によっては、全セルを実行するまで図や操作結果が更新されません。

教材のソースを編集するときだけ、`uv run marimo edit 02-regression/notebook.py` を使います。その場合は全セルを実行し、変更後の自動実行を有効にして動作を確認してください。

終了は起動したターミナルで `Ctrl+C`、再開は同じ場所で同じ起動コマンドです。

## 章の流れと操作できる図

1. **広さから家賃を予測する**：入力・予測・正解・パラメータの区別と、学習の流れの図。
2. **平均二乗誤差（MSE）**：5件の残差と二乗誤差を正方形で見る。NumPyでMSEを計算するコード欄（「実行」で再計算）。
3. **損失の地形**（操作できる図）：傾き w・切片 b の平面を押していろいろな直線を試し、次に損失の地形を表示し、最後に谷底（最小二乗法の解）を確かめる。
4. **重回帰**（操作できる図）：駅からの距離で色分けした散布図で、「広さだけ」と「広さ＋駅徒歩」の予測を切り替える。
5. **多項式回帰と過学習**：3次と9次を訓練データだけで比べ、次に検証データを重ねる。次数1〜9を切り替える図（操作できる図）で、訓練MSEと検証MSEを比べる。最後に訓練データ10回と40回を比べる。
6. **L2正則化**（操作できる図）：9次のまま λ を変え、曲線・MSE・重みの大きさの変化を見る。
7. **テストデータ**：検証MSEで選んだモデルを、最後に一度だけテストデータで評価する。

章末に確認問題が5問あります。
