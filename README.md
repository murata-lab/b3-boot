# B3 機械学習入門

プログラミングと大学初年級の数学を学んだことがあり、Python・機械学習・PyTorchをこれから学ぶB3向けの教材です。

回帰からニューラルネットワークへ進み、短いPyTorchの学習コードを読んで実行できることを目指します。01〜05では主に教師あり学習を扱います。

> 現在は教材を制作中です。01〜05の教材を作成しました。

## はじめに

まず[環境の準備（SETUP.md）](SETUP.md)を読み、uv・marimoを準備します。その後、本編を01から順に進めます。セットアップは章番号に含めません。

macOSまたはWindowsのPC、インターネット接続、ブラウザ、Git導入済み・教材取得済みの状態を想定しています。Pythonやuvの事前導入は不要です。

## 教材を開く

教材ルートで、毎回このコマンドだけを実行します。

```sh
uv run python app.py
```

ブラウザに教材一覧が開きます。左上の **☰** を押すとサイドバーが開き、01〜05と教材一覧を行き来できます。章を変えるためにターミナルを操作する必要はありません。

01はコードを編集・実行できる画面、02〜05は本文・図・デモを操作する画面で開きます。一度開いた章はそのまま保持されるので、別の章から戻っても操作状態・スクロール位置が残ります（ページの再読み込み・終了でリセットされます）。

ブラウザが自動で開かない場合は、ターミナルに表示されるURLを開いてください。終了は `Ctrl+C` で、開いた教材もまとめて終了します。ポートが使用中なら `uv run python app.py --port 8001` を使えます。

## 進め方と時間の目安

本編は5章です。02〜05は各約1時間、環境準備と01は操作・説明に必要な時間を別に見積もります。所要時間は制作後の試読・動作確認で更新します。

02・03では「機械学習帳」を参考に、式の目的・記号・具体例を説明します。詳しい証明や導出は「機械学習帳」を実際にやったほうがよいです。本教材だけでもニューラルネットの基本の流れまでを追える構成にします。
