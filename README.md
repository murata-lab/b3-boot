# 機械学習入門

プログラミングと大学初年級の数学を学んだことがあり、Python・機械学習・PyTorchをこれから学ぶ人向けの教材です。

回帰からニューラルネットワークへ進み、短いPyTorchの学習コードを読んで実行できることを目指します。01〜05では主に教師あり学習を扱います。

## この教材のゴール

01〜05を読み終えたら、次の4つを説明できることを目指します。06は任意です。

- 入力・正解・予測・損失・パラメータを、具体例で区別できる。
- 「予測 → 損失 → 勾配 → 更新」の流れを説明できる。
- 訓練データでよい結果が出ても、それだけでは不十分な理由を説明できる。
- 用意されたコードの設定を一つ変え、結果の違いを説明できる。

Pythonは「用意されたコードを読み、少し変えて動かす」ために使います。学習コードをゼロから書けるようになるのは、この次の段階です。

**提出物はありません。** 分からなかった点はメモしておき、研究室のミーティングで聞いてください。

## 章ごとの到達点

| 章 | 読み終えたらできること |
|---|---|
| 01 Python入門 | セルの値を変えて実行し、出力を説明できる。NumPy配列の形（shape）を読める |
| 02 回帰とモデルの選び方 | 訓練誤差が小さいだけではモデルを選べない理由を説明できる |
| 03 線形分類と勾配降下法 | 重みを更新する向きと、学習率の役割を説明できる。多クラスの確率と損失を計算できる |
| 04 ニューラルネットワークと逆伝播 | 活性化関数の役割と、予測・勾配・更新の違いを説明できる |
| 05 PyTorchによる学習と評価 | 入出力の形と各層の処理をコードと対応付ける。設定を訓練・検証の結果で比べ、選んだモデルを保存して最後にテストできる |
| 06 特徴空間と次元削減（任意） | モデルが作った特徴量を2次元で見る目的と、図から判断できる範囲を説明できる |

05では、6節まで読んだ後に設定を一つ変えて比較し、7・8節へ進みます。

各章に「確認問題」が5問あります（長い05は途中に2問、最後に3問）。選ぶとすぐに解説が出ます。答えを誰かに提出する必要はありません。

- **必須**：本文として表示されている部分です。
- **任意**：「（任意）」と付いた見出しや折りたたみです。飛ばして先へ進んでかまいません。

### 05の設定を一つ変えて比べる

05の5節の最後の行 `train_mnist(epochs=5, learning_rate=0.3)` で、次のどれか一つだけを変えて学習し直します。

- `epochs`（何周学習するか）
- `learning_rate`（学習率）
- `train_size`（訓練データの枚数。`train_mnist(..., train_size=5_000)` のように加える）
- `model.py` の隠れ層のニューロン数（2か所ある `128` を同じ値に変える。終わったら `128` に戻す）

変更前に、初期設定（訓練40,000枚・隠れ層128個・学習率0.3・5エポック）の**最終訓練損失・検証損失・検証正解率**を図5の出力から1行メモします。再学習すると前の結果は画面から失われます。

変えたセルを ▶ で実行したら、実行待ちになった図5と説明のセルまで上から順に実行します。`model.py` の隠れ層を変えた場合は、章を開き直して新しい形を読み込みます。

変える前に「図5の訓練・検証の損失と正解率はどうなるか」を予想し、次の4項目を一文ずつメモします。

1. 変えた設定
2. 予想
3. 結果（訓練・検証の損失と正解率。初期設定のメモと比べる）
4. 予想と違った点、考えたこと

このメモは提出不要です。ミーティングで話すときの材料にしてください。

比較を終えたら、**検証結果で設定を一つ選び**、その設定で学習したモデルを7節で保存・読み込みします。8節のボタンで初めてテスト正解率を測ります。テスト結果を見て設定選びに戻らないことが、「テストは最後に一度だけ」の意味です。

## はじめに

環境の準備は配属時に行います。Gitの導入と教材の取得（clone）までは一緒に行い、その後は[環境の準備（SETUP.md）](SETUP.md)を読みながら、uv・marimoを自分で準備します。

macOSまたはWindowsのPC、インターネット接続、ブラウザ、Git導入済み・教材取得済みの状態を想定しています。Pythonやuvの事前導入は不要です。

## 教材を開く

教材ルートで、毎回このコマンドだけを実行します。

```sh
uv run python app.py
```

ブラウザに教材一覧が開きます。左上の **☰** を押すとサイドバーが開き、01〜06と教材一覧を行き来できます。章を変えるためにターミナルを操作する必要はありません。

01・05はコードを編集・実行できる画面、02〜04・06は本文・図・デモを操作する画面で開きます。一度開いた章はそのまま保持されるので、別の章から戻っても操作状態・スクロール位置が残ります（ページの再読み込み・終了でリセットされます）。

ブラウザが自動で開かない場合は、ターミナルに表示されるURLを開いてください。終了は `Ctrl+C` で、開いた教材もまとめて終了します。ポートが使用中なら `uv run python app.py --port 8001` を使えます。
