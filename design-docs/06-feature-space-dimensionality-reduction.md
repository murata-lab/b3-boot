# 06 特徴量と潜在空間・次元削減（任意）構成案

作成日：2026-09-25

## 位置付けと到達点

章全体を任意とする。05で扱ったMNISTの分類モデルを使い、「ニューラルネットが画像をどう表現しているかを、次元削減で見てみる」を軸にする。

読了後に、次を自分の言葉で説明できることを目指す。

- 画素値、モデルが作った特徴量、予測スコアの違い。
- 高次元の特徴量を2次元で見る目的と、そこで情報が失われること。
- PCA・Isomap・UMAPが、それぞれ何を手掛かりに低次元の表現を作るか。
- 学習前後の特徴量の図から観察できることと、図だけでは判断できないこと。

流れは「特徴量 → 空間 → PCA → Isomap → UMAP → 学習した特徴量の観察」。手法の紹介を、最初の「モデルの中で何が起きたのか」という疑問につなげる。

## 1. モデルの途中では、画像は何になっている？

05のモデルをそのまま使う。

`784個の画素値 → 隠れ層の128個の値 → 10個のスコア`

1枚の画像を入れ、ReLUを通した後の隠れ層の128個の値を取り出す。この値の組を、その画像についてモデルが作った特徴量・表現として紹介する。

- 02の「広さ・駅徒歩」は、人が選んだ特徴量だった。
- ニューラルネットでは、予測に使う特徴量の作り方も学習する。
- 128個の値のそれぞれに、人が読める意味が付いているとは限らない。

画像と値の列を対応させ、「モデルの中を見る」が何をすることなのかを具体的にする。次に、この値の組を空間の1点として捉える。

## 2. 画像1枚を、空間の1点として見る

2個の特徴量なら平面上の点、3個なら立体中の点。その延長として、128個なら128次元の空間の点と導入する。「次元」は、1点を表すための座標の数と説明する。

モデル内部の表現が作る空間を特徴空間、文脈によっては潜在空間と呼ぶことに触れる。潜在空間という言葉は、2次元に描いた図だけを指すわけではないと整理する。

次元削減の図に進む前に、あるMNIST画像と「画素値で近い画像」「学習後の特徴量で近い画像」を並べる。表し方が変わると、似ている画像の選ばれ方も変わることを観察する。

ここから「128次元の点の集まりを、どうすれば目で見られるか」へつなぐ。

## 3. 128次元を、どうやって紙の上に描く？ — PCA

次元削減の必要性を説明し、最初の方法としてPCAを短く扱う。

斜めに細長く広がった2次元の点群を、1本の軸へ写す例を使う。

- 軸の向きによって、写した後の点の重なり方が変わる。
- PCAは、写した点のばらつきが大きくなる向きを選ぶ。
- 2次元にするときは、互いに直交する二つの方向を使う。

固有値の導出までは進めず、軸を選んで写すことと、情報を一部失うことまで説明する。MNISTの特徴量もPCAで一度描く。

次に、データが曲がって広がっている場合にも、同じ方法でその形を捉えられるかを考える。

## 4. 曲がったデータを広げる — Isomap

丸めた紙のような点群を使い、「空間を直線で結んだ距離」と「紙に沿って進む距離」の違いを見せる。3次元に曲がっていても、紙の上の位置は二つの座標で表せるところから、多様体の考え方へ進む。

仕組みは三段階で追う。

1. 近くの点どうしを結ぶ。
2. 線をたどる最短経路で、紙に沿った距離を近似する。
3. その距離をなるべく保つように、低次元へ配置する。

近傍を広げすぎると紙の別の面へ「近道」ができる例も見せ、近傍の選び方と結果の関係を説明する。

次に、近所の点どうしのつながりを別の方法で低次元へ写すUMAPへ進む。

## 5. 近所のつながりを写す — UMAP

Isomapと共通する「近傍の点を結ぶ」から出発し、UMAPの工夫を説明する。

- 各点の周囲の密集具合を考慮して、近所とのつながりに強さを付ける。
- 低次元側にも点を置く。
- 元のつながりを再現するように、点の位置を少しずつ動かす。

「つながりの強い点を近づける力」と「点が一か所に潰れないようにする力」の図を使い、03・04の「損失を小さくするように更新する」話へつなげる。

位相幾何の定式化までは入れず、入力から配置ができるまでを追える深さにする。仕組みを理解したところで、MNISTの特徴量へ戻る。

## 6. MNISTに戻る — 学習すると、特徴量はどう変わる？

この節を章の見せ場にする。同じ画像について、次を比較する。

- 元の784個の画素値。
- 学習前の128個の特徴量。
- 学習後の128個の特徴量。

次元削減してから正解の数字で色を付け、同じ数字のまとまりや、混ざっている画像を観察する。点を選ぶと元画像を見られるようにして、「この4と9は確かに似ている」と図と実物をつなぐ。

説明の中心は、分類の学習を通じて、最後の層が数字を分けやすい表現が作られること。「同じ数字を必ず一か所へ集めるように学習した」とは説明せず、実際の結果に合わせて書く。

モデルの学習には正解ラベルを使い、今回の次元削減にはラベルを渡さず、色付けにだけ使うことも区別する。

最後に、同じ特徴量でもUMAPの設定で配置が変わる例を置く。島どうしの距離や島の大きさを、そのまま数字の類似度やばらつきと読めるわけではないところまで扱う。

## 図・操作・確認問題

操作できる図は、次の3個程度に絞る。

1. PCAの投影方向：写す向きと点の重なり方の対応を見る。
2. Isomapの近傍：つなぐ範囲と、紙に沿った経路・近道の対応を見る。
3. MNISTの表現比較：入力・学習前・学習後を比較し、点に対応する元画像を見る。

UMAPの仕組みは、段階的な静止図で説明する。UMAPの設定による配置の違いも、まずは同じデータを並べた静止図で扱う。

章末に、用語の暗記ではなく、この章で扱った判断や区別を問う確認問題を5問置く。選ぶとすぐに解説が出る、既存章と同じ形式にする。

## 今回の範囲と実装前の確認

オートエンコーダ・VAE・t-SNEまでは広げない。PCAは次元削減の入口、IsomapとUMAPは仕組みまで扱う。

この文書は構成案であり、図の結果は未検証。実装時には、近い画像の比較、学習前後の特徴量、Isomapの近道が、説明したい現象を実際にはっきり示すかを数値と図で確認する。見た目のまとまりだけから、分類性能が高いと結論付けない。
