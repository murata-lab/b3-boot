# 03 線形分類と勾配降下法

文章と図を読み、いくつかの図を操作しながら、分類のモデル・交差エントロピー・勾配降下法・学習率・ミニバッチ・softmaxを学びます。「（任意）」と付いた折りたたみは飛ばしてかまいません。途中に一か所、数行のコードを書き換えて試せる欄があります。

[環境の準備](../SETUP.md)を済ませ、ターミナルで教材ルート（`README.md` と `SETUP.md` がある `ml-bootcamp` フォルダ）へ移動します。`03-classification` の中では実行しません。

## 章の流れと操作できる図

1. **雨が降るかを確率で予測する**：6月の30日間の朝の湿度と、その日に雨が降ったか。湿度の区間ごとの雨の割合から、スコアをsigmoidで確率に変えるロジスティック回帰へ進む。
2. **決定境界**：湿度と気圧の変化の二つの特徴量で、予報の境目が直線になることを見る。
3. **交差エントロピー**：予報が同じ三つのモデルを比べ、正解率では区別できない違いを「正解に与えた確率」で測る。尤度・最尤推定との関係は任意の折りたたみ。
4. **勾配降下法**（操作できる図）：1回の更新を「① 予測して損失を計算 → ② 傾きを求める → ③ w を更新する」の3段に分け、ボタン1回で1段ずつ進める。慣れたら1回分ずつまとめて進められる。
5. **学習率**（操作できる図）：学習率 0.002・0.01・0.15 を切り替え、遅すぎる・ちょうどよい・谷を飛び越えて落ち着かない、を比べる。NumPyで勾配降下法を書いたコード欄（▶ で実行）。
6. **勾配とミニバッチ**：パラメータが多いときの勾配、バッチ・ミニバッチ・SGDの違い。3つの方法の損失の比較は任意の折りたたみ。
7. **softmax**：雨かどうかの二つから、晴れ・くもり・雨の3クラスへ。スコアを確率に変え、正解クラスの確率から損失を計算する。

章末に確認問題が5問あります。
