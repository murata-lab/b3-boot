# 03 線形分類と勾配降下法

線形二値分類から、尤度・最尤推定、交差エントロピー、勾配降下法、学習率、バッチ・ミニバッチ・SGD、多クラス分類へ進みます。本文は [notebook.py](notebook.py) にあります。文章・数式・図を読んで学ぶ、約60分の教材です。読了時間は対象読者による試読前の目安です。

動かす図は重みの更新の一つだけです。「進む」で一回更新し、「戻る」で前の状態を見返します。「ループ再生」では初期状態と9回の更新を繰り返し表示します。同じボタンで一時停止できます。学習率と3手法は静止図で比較します。

## 開き方

[環境の準備](../SETUP.md)を済ませ、ターミナルで教材ルート（`README.md` と `SETUP.md` がある `b3-ml-bootcamp` フォルダ）へ移動します。

全章共通の入口を開きます。VS Codeのターミナルでも同じコマンドです。

```sh
uv run python app.py
```

教材一覧、または左上の **☰** メニューから「03 線形分類と勾配降下法」を選びます。すでに入口を開いている場合は、サイドバーで章を選ぶだけです。

ブラウザが自動で開かない場合は、ターミナルに表示されたURLを開いてください。コードの入力・書き換えは不要です。終了は起動したターミナルで `Ctrl+C`、再開は同じ起動コマンドです。

ソースを編集するときだけ、`uv run marimo edit 03-classification/notebook.py` を使います。

本文・Pythonの計算処理はすべて `notebook.py` に含めています。再生用の `player.html`・`player.js` を同じフォルダから読み込みます。別のPythonファイル、外部データ、GPU、追加の描画ライブラリは不要です。書き出したHTMLでも、同じ図を操作できます。
