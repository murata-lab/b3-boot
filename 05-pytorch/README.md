# 05 PyTorchによる学習と評価

手書き数字の画像（MNIST）を分類するネットワークをPyTorchで学習します。6節まで読んだら設定を検証結果で比べ、7節で選んだモデルを保存し、8節でテスト画像を使って最終評価します。

他の章より長めです。03の勾配降下法・ミニバッチ・softmax、04のネットワークと逆伝播を前提にします。

## 開き方

[環境の準備](../SETUP.md)を済ませ、ターミナルで教材ルート（`README.md` と `SETUP.md` がある `ml-bootcamp` フォルダ）へ移動します。`05-pytorch` の中では実行しません。データや重みの保存先が、教材ルートからの相対パスで書いてあるためです。

```sh
uv run python app.py
```

教材一覧、または左上の **☰** メニューから「05 PyTorchによる学習と評価」を選びます。

開くと、学習と検証までのセルを一度実行します（初回はMNISTのダウンロードを含むので、ネット接続が必要です）。テスト評価は8節のボタンを押すまで実行しません。その後は、セルを書き換えて ▶ で実行しても、その結果を使う下のセルは自動では実行されず、実行待ち（色が薄くなり、右上の ▶ が黄色）になります。`model.py` を書き換えたときも、それを使うセルが実行待ちになります。

単独で開く場合も、現在地は教材ルートにします。

```sh
uv run marimo edit 05-pytorch/notebook.py
```

終了は起動したターミナルで `Ctrl+C` です。

## 章の流れ

1. **手書き数字のデータ**：MNISTをダウンロードし、画像と正解ラベルを見る。1枚の画像が28×28の数の表であることを確かめ、Tensorにする。
2. **モデルを読み込む**：`model.py` の `MLP`（784→128→10、ReLU）を読み、データの形が `[B, 1, 28, 28]` → `[B, 10]` と変わることを確かめる。
3. **データを分ける**：公式の訓練用60,000枚から検証5,000枚・訓練40,000枚を、重ならないように選ぶ。テスト用10,000枚は最後まで使わない。
4. **学習の部品**：DataLoader、損失関数、1回の重みの更新（`step()` が $\theta \leftarrow \theta - \eta\nabla L$ と同じになることをコードで確かめる）、成績を測る関数。
5. **学習する**：部品をつなげた `train_mnist` で5エポック学習し、訓練・検証の損失と正解率をグラフで見る。
6. **訓練データでの成績だけでは分からないこと**：訓練データを1,000枚に減らすと、訓練データでは99%当たるのに、検証データでは86%程度にとどまる。
7. **保存と読み込み**：設定を検証結果で選んでから `state_dict` を保存し、新しい `MLP()` に読み込んで検証成績を確かめる。
8. **最終テスト**：選んだモデルでボタンを押し、テスト用10,000枚の正解率を測る。間違えた画像を押すと、モデルが10個の数字に付けた確率を見られる。

確認問題は、4節の終わりに2問、章末に3問あります（選ぶとすぐに解説が出ます）。

## 設定と実測

初期設定は、訓練40,000枚・5エポック・batch 128・SGD（学習率0.3）・seed 42です。optimizerには、03の勾配降下法そのものであるSGDを使っています。2026-09-24にApple M2のCPUで、この設定の学習は約2秒、検証正解率95.9%でした。配布例を最終評価した際のテスト正解率は **96.53%** です。この値は設定の候補選びには使いません。性能と所要時間は環境により少し変わります。
