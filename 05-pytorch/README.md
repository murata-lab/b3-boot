# 05 PyTorchによる学習と評価

`model.py` の実ファイルを読み、**marimoのコードセルを編集・実行して**MNISTの学習、重みの保存、読み込み、テストまで進める教材です。処理を隠す実習用ボタンはありません。

## 開き方

[環境の準備](../SETUP.md)を済ませ、現在地を `b3-ml-bootcamp` にして実行します。

```sh
uv sync
uv run python app.py
```

教材一覧から05を開きます。05はコードを編集できる画面で開きます。すでに古いアプリが動いている場合は、起動したターミナルで `Ctrl+C` を押して再起動し、ブラウザを再読み込みしてください。

単独で開く場合も、現在地は教材全体のフォルダに揃えます。

```sh
uv run marimo edit 05-pytorch/notebook.py
```

## 進め方

[notebook.py](notebook.py) の説明を読み、上から順にコードセルを選んで **Shift+Enter** で実行します。`model.py` だけは行番号付きのファイル表示で読みます。

1. `from model import MLP`、`model = MLP()`、`print(model)` で読み込んだモデルの層を表示。
2. `MNIST(..., download=True)` でデータを取得し、実際の画像とTensorの形を確認。
3. 過学習とデータを分ける理由を学び、訓練40,000枚・検証5,000枚を重ならないように選ぶ。
4. 損失の計算・1回の重み更新・検証を短い例で確かめる。
5. 「部品をつなげて、実際に学習してみよう」の全体コードで、import・データ準備から5 epochの学習・検証まで実行。
6. 検証損失が最小の重みを保存し、新しいモデルへ読み込む。
7. 公式テスト10,000枚で正解率を測り、画像の予測と間違いを確認。

アプリから開くと初回は全セルを実行し、実際の出力を表示します（取得・学習・保存・テストを含みます）。その後の変更に影響されるセルは実行待ちになり、自動で学習し直さない設定です。上部の **Run all** は取得・学習・保存・テストをまとめて実行する操作です。単独起動ではmarimoのRuntime設定に従います。出力がまだない場合はRun allで初回実行するか、上から順に各セルを実行できます。

学習セルの再実行は毎回初期値から始めます。実際の学習設定を変えるときは、全体コードの末尾の `train_mnist(...)` に渡す数値を編集し、学習以降の実行待ちセルを順に実行してください。保存セルの再実行は同名の重みを上書きします。

全体コードは前のセルの変数に依存せず、モデル定義の `model.py` と導入済みライブラリがあれば学習できます。部品の確認用セルの設定とは独立しています。

## 本編の保存先と実測

保存先は、それを使うコードセルで直接指定します。`config.py` の編集は不要です。

| 場所（起動時の現在地から） | 内容 |
|---|---|
| `data/MNIST/` | 取得済みの画像。以後は再利用 |
| `outputs/05-pytorch/notebook/mnist_mlp.pt` | 自分で学習し、検証結果から選んだ重み |

読解と実習を合わせて約60分が目安です。CPUで2〜3分以内を目指し、40,000枚・5 epoch・batch 128・学習率0.001・seed 42を用意しています。2026-09-12のApple M2で、改訂後のコードを一巡し、学習・検証約2秒、テスト正解率 **96.34%** を確認しました。性能と所要時間は環境により変わり、初回取得と依存ライブラリの導入は別です。
