# 04 ニューラルネットワークと逆伝播

部屋の気温と湿度から「快適かどうか」を予測する例で、直線では分けられないデータを分けるニューラルネットワークの仕組みと、その重みの勾配を求める逆伝播、重みの更新を学びます。「（任意）」と付いた折りたたみは飛ばしてかまいません。途中に一か所、数行のコードを書き換えて試せる欄があります。

03の重み付き和・sigmoid・交差エントロピー・勾配降下法を前提にします。

## 開き方

[環境の準備](../SETUP.md)を済ませ、ターミナルで教材ルート（`README.md` と `SETUP.md` がある `ml-bootcamp` フォルダ）へ移動します。`04-neural-networks` の中では実行しません。

全章共通の入口を開きます。VS Codeのターミナルでも同じコマンドです。

```sh
uv run python app.py
```

教材一覧、または左上の **☰** メニューから「04 ニューラルネットワークと逆伝播」を選びます。すでに入口を開いている場合は、サイドバーで章を選ぶだけです。

ブラウザが自動で開かない場合は、ターミナルに表示されたURLを開いてください。`run`は教材をアプリとして表示するモードです。本文・図・ボタンが表示され、操作すると図が変わります。

教材のソースを編集するときだけ、`uv run marimo edit 04-neural-networks/notebook.py` を使います。その場合は全セルを実行し、変更後の自動実行を有効にして動作を確認してください。

終了は起動したターミナルで `Ctrl+C`、再開は同じ場所で同じ起動コマンドです。

## 章の流れと操作できる図

1. **直線では分けられないデータ**：快適な部屋を不快な部屋が囲むデータを、03の線形モデルで分けてみる（直線では半分ほどしか当たらない）。
2. **ニューラルネットワークの計算**：よく見るネットワークの図から、各ニューロンの計算（重み付き和 → 活性化関数）とReLUを説明し、この章で使うネットワークの中身を見る。活性化関数を外すと一つの重み付き和にまとまってしまう理由。ほかの活性化関数（sigmoid・tanh）の式とグラフは任意の折りたたみ。
3. **学習すると、境界が折れ曲がる**（操作できる図）：ランダムな重みから学習を進め、ネットワークと線形モデルの境界・損失を比べる。ニューロンの数を変えた結果も見る。
4. **順伝播**（一段ずつ進める図）：学習前のネットワークで、26℃・40%の部屋の予測を、入力 → 重み付き和 → ReLU → 出力の重み付き和 → sigmoid の順に計算する。
5. **連鎖律と逆伝播**：バイアスの小さな変化が損失まで伝わる様子から連鎖律を導き、全パラメータの勾配を出力側から求める（一段ずつ進める図：損失 → 出力 → 隠れ層の出力 → ReLU → 重みとバイアス）。NumPyで順伝播・逆伝播を計算するコード欄（▶で実行）。
6. **更新**：求めた勾配で重みを一回更新し、予測が正解に近づくことを確かめる。

章末に確認問題が5問あります。
