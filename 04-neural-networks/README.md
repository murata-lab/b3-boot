# 04 ニューラルネットワークと逆伝播

手書き数字の認識から、線形モデルの制約とNNの利点を説明します。その後、隠れ層2層・各層3ニューロンの小さな例で、予測・損失・逆伝播・重みの更新を追います。

本文は [notebook.py](notebook.py) にあります。文章・数式・図と再生デモを読む教材で、コードの入力・書き換えは不要です。03の重み付き和・損失・勾配更新を前提にします。目安は約60分です（対象読者の試読時間は未測定）。

## 開き方

[環境の準備](../SETUP.md)を済ませ、ターミナルで教材ルート（`README.md` と `SETUP.md` がある `b3-ml-bootcamp` フォルダ）へ移動します。`04-neural-networks` の中では実行しません。

教材をアプリとして開きます。VS Codeのターミナルでも同じコマンドです。

```sh
uv run python app.py
```

教材一覧、または左上の **☰** メニューから「04 ニューラルネットワークと逆伝播」を選びます。すでに入口を開いている場合は、サイドバーで章を選ぶだけです。

ブラウザが自動で開かない場合は、ターミナルに表示されたURLを開いてください。`run`では編集用セル枠が出ず、本文・図・再生デモが表示されます。「計算の中身を見る」も任意に開けます。

ソースを編集するときだけ、`uv run marimo edit 04-neural-networks/notebook.py` を使います。編集画面にはセルの境界が残り、実行設定によっては起動後に全セルの実行が必要です。

終了は起動したターミナルで `Ctrl+C`。再開は同じ場所で同じコマンドです。

## デモの読み方

- **入力から予測まで**：14コマ。入力→隠れ層1→隠れ層2→予測と進みます。
- **損失・連鎖律・逆伝播**：15コマ。一本の経路の微分の積、複数経路の寄与の加算、各重みの勾配を追います。
- **更新前と更新後を見比べる**：16コマ。左に更新前を残し、右で同じ入力を更新後の重みで計算し直します。

操作は「戻る」「進む」「自動ループ再生」の3つだけです。最初は停止しています。自動再生は最後まで進むと先頭に戻り、同じボタンをもう一度押すと停止します。通常は1秒ごとに進み、最後の結果を2秒表示してから繰り返します。前後送りやループで学習が追加されることはありません。

別のデモを再生・操作したり、デモが画面外に出たり、ブラウザのタブを離れたりすると再生を停止します。狭い画面では比較図や長い数式・表の領域を横にスクロールできます。独立した自由試行やパラメータの自由編集はありません。

MNISTの画像12枚を同梱しているため、教材の起動時にデータをダウンロードしません。GPUやPyTorchは不要です。画像の出典・選び方・利用条件は [assets/README.md](assets/README.md) にあります。

計算とSVG生成は [notebook.py](notebook.py) 内にまとめています。履歴の再生は [player.html](player.html) を使います。別のPythonファイルは不要です。通常の学習では読む必要はありません。教材はこのフォルダで完結し、制作側の設計文書に依存しません。

05ではMNISTの分類へ戻り、PyTorchの学習と評価へ進みます。
