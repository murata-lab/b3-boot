## 到達目標と内容

到達目標は、中間層の出力をデータの特徴表現として理解し、次元圧縮した図と元画像を対応付けて観察できること。さらに、特徴は近傍検索などにも利用できることと、二次元図の限界を理解する。

### 1. 中間層が作る特徴表現（10分）

具体例は `784 → 128 → 10` のMLPとする。

```text
MNIST画像 [28, 28]
  → 一列に並べた入力 [784]
  → 特徴抽出部分 fθ
  → 特徴ベクトル h [128]
      ├→ 最後の全結合層 Wh+b → クラス別スコア [10]
      └→ 可視化用の次元圧縮 → 表示座標 [2]
```

- 画像1枚が特徴空間の1点に対応し、N枚をまとめると特徴行列は `[N, 128]` になる。
- 分類器を `h = fθ(x)` と `s = Wh + b` に分けて読む。誤差に基づく学習によって、最終層が分類に使える表現が作られる。
- 入力空間・特徴空間・表示用の二次元空間を区別する。次元数はモデルの設計で変わり、特徴抽出が常に次元圧縮になるとは限らない。
- 中間特徴は一般に非線形な変換の結果。「射影」とだけ呼んで、直交射影や距離保存を暗に仮定しない。
- 128個の軸がそれぞれ「丸さ」「傾き」などに対応するとは限らない。特徴は複数の成分に分散して表現されることがある。

用語は特徴量・特徴ベクトル・表現（representation）・埋め込み（embedding）を対応付ける。ここでは主に「特徴空間」と呼び、潜在空間という語は後半のAutoencoderへの接続でも説明する。分類器の任意の中間層と、生成モデルの潜在変数を同一視しない。

### 2. 学習前後の表現（10分）

同じ観察用画像について、未学習モデルと学習済みモデルで横並びで比較できるように。分類に使える特徴への変化を観察する。

「学習すると必ず10個の丸い塊ができる」とは説明しない。分類損失は正しいクラスの予測を促すが、同じラベルの点の距離を直接小さくするとは限らない。分離の程度や誤分類例を実データで確かめる。

### 3. 次元圧縮の基本（15分）

PCAを基本手法として説明し、t-SNEは可視化の比較用に一つ加える。UMAPは名称と追加資料の紹介に留め、三手法の詳細説明はしない。

- PCA：データのばらつきを多く残す軸を選ぶ線形な次元圧縮。最初は二次元の点群を一次元へ写す小さな図で説明し、その後128次元から2次元へ進む。寄与率で、表示に残る分散の割合を確認する。クラスを分ける目的の手法ではない。[PCA公式資料](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html)
- t-SNE：近傍関係を低次元で表すことを目指す可視化手法として概要を説明する。PCAとの見え方の違いを示し、最適化式の導出は扱わない。[t-SNE公式資料](https://scikit-learn.org/stable/modules/generated/sklearn.manifold.TSNE.html)
- 二次元化では情報を失う。図の重なりだけで元の128次元でも分離できないとは言えず、島同士の距離や大きさもそのまま解釈できない。[可視化の読み方](https://distill.pub/2016/misread-tsne/)

2. 点の選択：元画像、正解、予測、特徴空間の近傍画像を表示する。近傍は二次元の画面上ではなく、元の128次元特徴で求め、使用する距離を明示する。画素空間での近傍とも比較できるようにする。

これにより、数字ごとのまとまり、同じ数字の字形の違い、異なる数字で似た形、誤分類された画像を観察する。距離の選び方やスケールで近傍が変わることは短く補足する。

既定では学習に使っていない固定の観察用サブセットを用いる。可視化を探索・調整に使ったデータを、手つかずの最終テストとして扱わない。

表示切り替えのたびに訓練やt-SNEを走らせず、準備済みの結果で待ち時間を抑える。作成条件・モデル・層・サンプルID・seedを記録し、再生成手順は補足とする。

学習段階ごとにPCAやt-SNEを独立に当てた図では座標系が異なるため、点の移動量を学習による変化として読ませない。この教材の基本は静的な並列比較にし、epochスライダーによる連続移動は追加候補とする。採用時は固定したPCA基底など、比較方法を明示する。

### 5. 潜在空間と研究での利用（5分）

特徴の利用先として、類似画像検索、クラスタリング、別タスクへの特徴の再利用を短く紹介する。「よい特徴」は学習目的や利用先に依存することを押さえる。

Autoencoderは `画像 → encoder → z → decoder → 再構成画像` の図を一つ示し、分類のための表現と、入力を再構成するための表現の違いを説明する。ここでは訓練実装は扱わない。分類器の特徴から画像を復元するには別の仕組みが必要であり、任意の中間特徴を操作すれば画像を生成できるとは説明しない。

VAE、潜在空間の補間、自己教師あり学習・対照学習の詳細は後続教材へ回す。背景資料：[Representation Learning: A Review and New Perspectives](https://arxiv.org/abs/1206.5538)。
