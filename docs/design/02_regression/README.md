## 題材と説明の順序

単回帰は学習時間から得点を予測する合成データを使う。現実の因果関係や得点の保証を表すものではないと添える。複数の入力の例では練習回数を加える。曲線への拡張では別の、曲がった関係にノイズを加えた合成データへ移る。03の勾配法導入は単回帰の固定例とMSEを再利用する。

| 内容・時間 | 文章・数式・図で説明すること | 説明に沿って確かめること |
|---|---|---|
| 予測と汎化への入口・5分 | 入力・正解・予測。観測済みの点から、まだ正解を知らない入力の値を予測したい | 既知の点と新しい入力を図で区別する。予測を出すときは正解を使わない |
| 単回帰とMSE・12分 | 直線、符号付きのずれ、二乗、平均の順に損失を組み立てる | w、次にbを動かし、選んだ点の誤差と全体のMSEを比べる |
| 重回帰から多項式へ・10分 | 複数の特徴量の寄与を足す。元の入力からx²などを作ると曲線も表せる | 寄与と予測の対応、次数1と3の式・特徴量表・曲線を比べる |
| 汎化・過学習・モデル選択・15分 | 訓練への当てはまりと未知データへの性能、train / validation / testの役割 | 同じ点で次数1・3・5・9を比較し、訓練MSEだけでは選べない例を読む |
| L2正則化・10分 | 当てはまりと係数の大きさを両方考える目的関数 | 次数を固定し、λなし・適度・強すぎる場合を曲線と誤差で比較する |
| まとめ・3分 | パラメータを学習し、検証で設定を選び、最後に評価する | 何を変え、何を根拠に選んだかを見返し、03の学習方法へつなぐ |

## 単回帰：一つのずれから全体の損失へ

最初の図には既知の点、予測直線、新しい入力への予測を載せ、直線を作る目的を文章で説明する。その後、予測式を定義する。

$$\hat y = wx + b,\qquad e_i = \hat y_i-y_i,\qquad L = \frac{1}{n}\sum_{i=1}^{n}e_i^2$$

wは傾き、bは切片、nは点の数。初期例は x = [1, 2, 3]、y = [2, 3, 5]、w = 1、b = 0。予測 [1, 2, 3]、残差 [−1, −1, −2]、二乗誤差 [1, 1, 4]、MSE = 2を図・数値代入・表で一致させる。配列コードの説明ではなく、3点の計算として表示する。

図の破線で各点の残差を示し、表で各二乗誤差を確認する。点ごとの説明文は図上に重ねない。MSEと予測式は図内の凡例下へまとめ、HTML・SVG中ではハット付き文字を使わず「予測値」と表記する。二乗で符号が消えること、大きなずれほど強く寄与すること、一点の改善だけでは全体の改善とは限らないことを文章で説明する。

w、次にbを動かした後、「MSEを最小にする直線に合わせる」で傾き・切片の操作値も最小二乗解に切り替える（表示用に小数6桁へ丸める）。何を最小にした結果かを添え、解法の導出は要求しない。観測した点への当てはまりを測っただけで、新しい点への性能はまだ確かめていないと次につなぐ。

## 重回帰と多項式：何を入力として足し合わせるか

まず6人の学習時間・練習回数・得点の表を提示する。同じ学習時間でも得点が異なるA・Bを起点に、特徴量を追加する目的を説明する。

$$\hat y = w_1x_1+w_2x_2+b$$

Dさんのx = [2, 3]、w = [4, 2]、b = 1では8 + 6 + 1 = 15。特徴量一つ／二つを切り替え、それぞれの最小二乗解へ合わせると、全員の正解・予測とMSEを比較できる。重みを手で動かすこともできる。学習時間だけでは同じ時間の人に同じ予測しか出せないと図と表で確認する。2特徴量で誤差が0になる説明用データであり、一般に保証される結果ではないと添える。

係数の求め方は操作前に説明する。MSEは係数の二次式であり、各係数についての傾きを0にした条件を連立して解く。残差の和と各特徴量×残差の和が0になる条件を短く示す。勾配法は03につなぎ、行列の詳細は任意の折りたたみにする。

続いて、一つの元の入力xから特徴量 x, x², …, xᵈ を作ると、同じ重み付き和で曲線を表せることを示す。

$$\hat y = b+\sum_{j=1}^{d}w_jx^j$$

「複数の入力を使う重回帰」と「多項式の次数を増やすこと」を区別し、多項式回帰は変換した特徴量を使う重回帰として扱えるとつなぐ。操作名は「次数d」。元の入力は一つ、切片を除く特徴量数はd、切片を含む係数数はd+1と明記する。xに対して曲線でも、係数に対しては線形なモデルである。

時刻と装置の出力の例で、観測点と直線の図を先に示す。次数を変えると、予測式・曲線・図内の訓練MSEが連動する。係数は既に説明した最小二乗法で求めると明示し、学習者に多数の重みを手で調整させない。次数を決めることと、その次数の係数を学習することを別の役割として説明する。3Dの回転操作は必須にしない。

## 汎化から過学習・モデル選択へ

汎化は、学習に使わなかった、同じ生成の仕組みから来るデータにも予測が通用することとして説明する。観測した点だけに合わせることが目的ではない。有限個の検証点・test点で測る誤差はその性能の推定であり、将来の全データへの保証ではない。入力の範囲や生成の仕組みが変わる場合には、そのまま通用するとは限らないと短く添える。

最初にtrain / validation / testの役割を図示する。訓練は係数を求めるため、検証は次数・λなどを選ぶため、testは選択後の評価のために使う。重み・切片をパラメータ、次数・λを学習前に決めるハイパーパラメータとして、実際の操作と対応付ける。

説明用の曲線データ・分割・seedを固定し、まず次数1・3・9の代表例を同じ軸で見せる。検証点を重ね、必要に応じて表示を切り替えられるようにする。低次数では関係を捉えきれない例（過少適合）、高次数では訓練誤差が小さくても検証誤差が大きい例（過学習）、その間の比較候補を文章と図で説明してから、候補を切り替えて確かめる。

横軸を次数1〜9、縦軸をMSEとするグラフを用意し、訓練・検証の2系列を比較する。操作中の次数をグラフで強調し、対応する予測曲線も示す。「次数が高ければ必ず悪い」「訓練と検証の差だけで過学習を断定できる」とは一般化しない。この固定例で何が観察できたかを述べ、モデル選択には検証誤差を使う。代表例が意図した関係を示すデータ条件は試作で確認し、生成条件を記録する。

候補選択中はtestの点・誤差・MSEを表示しない。正則化まで比較した後、最終評価専用の次数・λの入力欄と候補の予測図を同じ場所に用意する。「このモデルをテストデータで評価」で次数・λ・前処理・係数を固定し、同じ曲線にテスト点とMSEを追加する。最終評価の候補操作は固定し、前の比較用操作とは独立させる。説明をやり直しても、同じtestを再び手つかずの評価と呼ばない説明を残す。

## L2正則化：次数を減らす以外の調整

高次数のモデルを使ったまま、重みが大きくなることに罰則を加える考え方を文章と曲線で導入する。

$$J = L_{\mathrm{train}}+\lambda\sum_{j=1}^{d}w_j^2$$

切片は罰則から除く。多項式特徴量の標準化は訓練データの統計量だけで行い、次数ごとに必要な列を使う。データが同じ比較では各列の統計量も固定する。本文では標準化を「各特徴量の尺度を揃えてから係数を比べる」と短く説明し、係数は標準化後の特徴量に掛かる値と明記する。生のxのべきに掛かる係数と取り違えない表示にする。

主となる操作は「①3次・λ=0 → ②9次・λ=0 → ③9次・λ=0.0001 → ④9次・λ=10」の4段階とする。①→②は次数だけ、②→③→④はλだけを変える。前段階の曲線を灰色の破線、現段階を実線で重ね、訓練・検証MSEを「変更前→変更後」で図内に示す。その段階で何が改善・悪化したかを短く説明する。主張は、訓練への当てはまりを少し譲ることで検証誤差を下げられる場合があることと、正則化が強すぎると両方の誤差が増えることである。

説明後の任意比較ではλだけを操作し、そのλを使った次数1〜9の訓練・検証MSEを2系列で示す。各点の次数とMSEはカーソルを合わせて確認できるようにし、表示対象を選ぶだけの次数スライダーや個別の予測曲線は置かない。異なるλの目的関数ではなく、検証MSEで設定を選ぶ。

次数は使える項を変え、λはその項の係数の大きさに働くことを対比する。正則化を強めれば必ず汎化が良くなるとは説明せず、当てはまりを失う側も示す。
