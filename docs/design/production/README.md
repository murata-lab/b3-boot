## 目的と到達点

プログラミングと大学初年級の数学を学んだことがあり、Python・機械学習・PyTorchには不慣れなB3を想定する。回帰からニューラルネットワークへ進み、予測・損失・勾配・更新・評価の関係を理解し、一つの短いPyTorch学習コードを読んで通常のPythonとして実行できる状態を目指す。


## 学習順と時間

準備はSETUP.md、本編は01 Python→02 回帰→03 分類と勾配法→04 NNと逆伝播→05 PyTorchの順。おまけは本編後に案内し、A01以降の別番号にする。

本編02〜05は読解・必須操作・実行待ちを含め各約1時間を目標にする。01は簡単なPython説明に必要な分量とし、環境準備と別に見積もる。必修の合計は02〜05の約4時間に01・環境準備の所要時間を加え、実測で更新する。

1週間を使う場合は本編を1章ずつ進め、準備や復習にも時間を確保する。7日分の内容を埋めるために必修を増やさない。おまけ・追加実験・輪読は任意。A01の約1時間は独立した追加学習の目安とする。

## 説明と確認の方針

02〜04は文章・数式・図を中心に概念を説明し、理解を助ける箇所に条件を絞った操作・再生を添える。独立した自由試行は設けない。コードは理解を助けるときや計算の中身を見たいときに任意に参照できるものとし、入力・書き換え・コードの読解を完了条件にしない。01のPython説明でコードが多かったことを、02〜04の構成の基準にしない。

各章のまとまりと必要な説明順を優先し、全章を一つの問いや同じ題材の続きに揃えることは求めない。道具・概念・手法はできるだけ「何をしたいか→使う仕組み→具体例と操作→結果」の順に説明する。単純な文法に長い動機付けは強制しない。

| 題材 | 説明する目的 |
|---|---|
| uvと環境 | 依存関係を別プロジェクトと混ぜず、全章で同じ環境を使う |
| クラス・継承（05） | モデルの層と計算をまとめ、nn.Moduleが持つパラメータ管理などを利用する |
| データ分割 | 未知のデータでの性能を確かめる |
| 損失と勾配 | 予測のずれを数値化し、パラメータを変える方向を求める |
| 正則化 | 訓練データに合わせすぎることを抑える |
| 特徴表現と次元圧縮（A01） | モデルが取り出した情報を調べ、表示で失う情報も踏まえて観察する |

01には独立した自己確認を置かない。ループの出力や `uv add` と `import` の違いは説明の該当箇所で扱う。他章も同じ形式の小テストを一律に要求しない。必要な理解確認は図・操作・まとめの中で短く行い、解説も含めて時間を見積もる。独立した演習章・最終課題・提出レポートは作らない。

新しい式は目的→記号→小さな数値例→図との対応→結果の読み方を示す。コードとの対応はその理解を助ける場合だけ添える。章冒頭には範囲・前提・到達目標、末尾には短いまとめと関連する章への案内を置く。必修の用語を未説明のまま前提にしない。

02で予測・損失・汎化とモデル選択、03で具体的な勾配更新、04で多層モデルの勾配計算へ進む。正則化は02で基本概念、05で結果から判断する工夫として扱う。

説明中の操作は理解が深まる箇所に絞り、一度に変える要因を一つにして、初期状態へ戻せるようにする。過学習・発散などの必須例は代表条件で説明し、自由な操作で偶然見つけることに依存させない。学習曲線だけで原因を一意に断定しない。

## 分量と教材形式

02〜05は導入5分・説明35分・具体例や操作15分・まとめ5分を目安に、内容で調整する。05の個別配分は05の設計書を優先する。02〜05の時間超過時は説明を圧縮する前に、例や手法の数を減らす。特に03の多クラス分類までの範囲と、05のクラス説明から保存・復元までの範囲を試読する。

本文に残すのは到達点に必要な文章・式・図と例、代表的な手法。02〜04は概念の理解、05はそれらを一つの学習コードへ対応付ける知識を扱う。詳細な証明・一般化、多数の手法比較、APIの網羅、大規模なファイル分割や実験管理は補足へ回す。05で最初から全行を書かせることはしない。

01〜05とA01は説明・数式・図・コード・操作をmarimo内にまとめ、別のMarkdown本文と二重管理しない。操作をしなくても要点を追えるように初期図と結果の説明を残す。補助処理は本文を妨げないようにする。01・05では学習対象のコードを見せ、02・04は「計算の中身を見る」から参照できるようにする。03は補足の折りたたみとコード表示を置かない。05のmarimoと通常のPythonは同じデータ・モデル・設定とし、処理の対応を示す。

02〜04は[対話的な説明・再生仕様](interactive-explanations.md)に従い、文章・式・図の説明に必要な操作・再生を添える。02は予測・損失・汎化とモデル選択、03は分類から尤度・最尤推定、勾配更新と学習率、3種類の勾配降下法を説明する。03の学習率と3手法は静止図で比較する。動く図は反復更新の一つに絞り、一コマ一更新・初期状態を含め10状態・戻る／進む／ループ再生の3ボタンとする。04は手書き数字の認識→線形モデルの制約→NNの利点から、構造・順伝播・損失・連鎖律・逆伝播・更新へ進む。動く例はすべて隠れ層2層・各層3ニューロンに固定し、ReLUとニューロンの説明は数式・静止図で行う。更新と再推論は更新前を左、更新後を右に残して比較する。条件比較には図・式・損失の連動、計算順序には手動送りと自動再生を使う。操作数を一律に決めず、説明上の意味と必須の学習量で絞る。各章の時間配分は各章の設計書を優先する。

README・SETUP.mdと制作側の設計文書はMarkdownを使う。
