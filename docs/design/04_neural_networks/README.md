# 04 ニューラルネットワークと逆伝播

[設計一覧へ戻る](../README.md)

状態：手書き数字の認識→線形モデルの制約→NNの利点→構造・順伝播・逆伝播・更新という構成に更新（2026-09-11）。動く例はすべて隠れ層2層・各層3ニューロンに固定する。独立した自由試行は設けない。教材本文・図・3つの再生デモを実装し、数値とブラウザでの表示・操作を確認した。画像認識の精度比較は追加していない。所要時間は試読で確認する。[実装・検証記録](validation.md)を参照。

## 形式と到達点

文章・数式・図・アニメーション・marimoによるデモで説明する。手書き数字を認識する目的から、線形モデルの制約とNNの一般的な利点を説明し、「どう予測を作り、どう学習するのか」へ進む。特徴量の自動設計だけをNNの採用理由にせず、複雑な非線形関係の表現、モデル全体の学習、画像認識などでの実績を実例に結び付ける。

到達点は、予測を作る順伝播、勾配を求める逆伝播、重みを変える更新を区別して説明できること。コードの入力・実装・読解は要求しない。計算のコードは必要なときに任意に開いて参照できるようにし、05の学習コードへ接続する。読解・再生・比較を含め約1時間。

文章・数式・静止図で分かる内容に操作を追加しない。計算の順序、値と勾配の伝わり方、更新による変化にアニメーションとデモを使う。「説明に沿って確かめること」を各節へ一律に割り当てず、独立した「説明後に自分で試す」も置かない。[02〜04の対話的な説明・再生仕様](../production/interactive-explanations.md)の表示・再生仕様に従い、04の操作範囲は本設計を優先する。

| ニューロン・隠れ層・活性化・10分 | 一ニューロンの重み付き和・バイアス・ReLUを説明し、隠れ層2層・各3ニューロンの全体図へ広げる。活性化の有無は数式と静止図で説明する |
| 推論の順伝播・10分 | 小さな数値例で入力から2つの隠れ層を経て予測に至る計算を説明する。式・代入値・経路をコマ送り・再生で対応付ける |
| 損失・連鎖律・逆伝播・20分 | 予測と正解から損失を計算する。一本の経路の微分の積から全体へ広げ、複数経路の寄与の加算とReLUの微分を、説明と再生で示す |
| 更新と再推論・8分 | 勾配が揃ってから重みを更新する。左に更新前、右に更新後を並べ、同じ入力から右側の順伝播をやり直し、中間値・予測・損失を比較する |

時間超過時は同じ計算の再生回数や補足を減らし、順伝播・連鎖律・更新の意味と更新前後の比較を残す。自由試行の時間や操作課題は設けない。

## 導入：手書き数字の認識からNNへ

MNISTのような28×28画素の手書き数字を使い、同じ「3」でも太さ・傾き・書き方が異なる画像と、紛らわしい「5」などを並べる。「画像を入力し、0〜9のどの数字かを予測したい」と目的を示す。実際の画像を使い、ラベルを確認する。

線形モデルでは画像を784個の画素値xとして扱い、数字kごとに `s_k = w_kᵀx + b_k` を計算する。03の多クラス分類と同じく、スコアからsoftmaxで確率を作り、最大のクラスを予測する。画素・重み・スコアの対応を静止図で示す。

線形モデルでも数字の分類はできるが、元の画素の重み付き和では各スコアに対する画素の寄与が固定され、画素同士の複雑な組み合わせを直接表すことに制約がある、と説明する。「入力が二次元で一本の直線しか引けない」という導入や、XORによる説明は使わない。特徴量を非線形に変換すれば線形モデルで扱える関係も増えることは02との接続として短く認め、NNだけが解ける問題だとは説明しない。

そこから、NNには次の利点があると説明する。

- 非線形な変換を重ね、複雑な入力と出力の関係を表現できる。
- 隠れ層の変換も含め、モデル全体をデータに合わせて学習できる。
- 大量のデータと計算資源を活用し、画像・音声などで高い性能を実現してきた。

一般的な説明の参照先は[Deep learningの総説](https://doi.org/10.1038/nature14539)。実用上の成果を添える場合は、[ImageNetの画像認識研究](https://papers.nips.cc/paper_files/paper/2012/hash/c399862d3b9d6b76c8436e924a68c45b-Abstract.html)を短く紹介する。大規模CNNの実績と、本章の小さな全結合NNの性能を混同しない。読書は必須にしない。

導入は画像・文章・数式・静止図で完結させる。線形モデルとNNの予測結果を比較する場合は、同じ前処理・データ分割・評価指標を使い、学習と設定選択の条件を記録する。表示例の選び方と評価全体の結果を併記し、線形モデルの失敗例だけを恣意的に選ばない。未測定の正解率やNNの優位性を記載しない。比較用の学習済み重みと結果を配布して初回表示に学習待ちを入れず、04には学習開始や画像の自由入力の操作を追加しない。画像認識の実際の学習コードは05で扱う。

## 構造・活性化と、二つの例の役割

基本図は **入力→隠れ層1（3ニューロン）→隠れ層2（3ニューロン）→出力** とする。隠れ層は2層であり、各層のニューロン数が3個であることを明記する。入力層・出力層を隠れ層の数へ含めない。04の動く例はすべてこの隠れ層構成に統一し、層数・ニューロン数の変更UIは設けない。画像入力のNNを動かす追加例を制作する場合も `784→3→3→10` に揃える。この小構成で高い認識性能が得られると約束しない。05のモデル構成は05の設計で扱う。

最初に `z_j = Σ_i W_ji x_i + b_j`、`h_j = ReLU(z_j) = max(0, z_j)` を一つのニューロンの図と対応付ける。入力を丸、重みを矢印のラベル、総和をΣで示し、バイアスは上から定数1が重みbの矢印でΣへ入る別入力として描く。総和の後にReLUを通す。ReLUは折れ線のグラフと代表値で説明する。活性化なしでは `W²(W¹x+b¹)+b² = (W²W¹)x + (W²b¹+b²)` と一つのアフィン変換にまとめられることを示し、出力層まで同じことが成り立つと説明する。ニューロンを選んで値を見る操作や、ReLUあり／なしの切り替えデモは作らない。層ごとに必ず「線→部品→数字」の意味が割り当てられるとも説明しない。

計算過程の説明では、手で追える **入力2→隠れ層1の3ニューロン→隠れ層2の3ニューロン→出力1** の回帰NNを使う。出力は恒等関数、損失は `L = (1/2)(ŷ − y)²`。これは数字認識そのものではなく、共通する計算の仕組みを理解するための小例である。784画素の全計算やsoftmax・交差エントロピーの微分を連鎖律と同時に追う負担を減らすための切り替えと説明する。02のMSEとは係数・対象サンプル数が違い、03の分類で使った交差エントロピーから損失の種類も変わる。分類でも順伝播・逆伝播・更新の基本的な仕組みは共通である。

## 計算を追う共通画面

上から「現在の目的と工程」「再生操作」「計算グラフと数値代入」「この一手の説明」の順に置く。図の位置・大きさはステップ間で固定する。計算済みの値を残し、まだ計算していない数値は空欄にする。ニューロンの記号だけを表示し、「未計算」などの補助文言は表示しない。

- 操作は「戻る」「進む」「自動ループ再生」の3つのみとする。初期状態は停止。自動再生は通常1秒ごとに進み、最終結果を2秒表示した後に先頭へ戻って繰り返す。同じ再生ボタンで停止できる。前後送りでは停止し、端では対応するボタンを無効にする。先頭ボタン・位置スライダー・速度選択は置かない。
- 工程は「推論」「損失」「逆伝播」「更新」「更新後の推論」と名前を付ける。推論の説明は予測で終了し、正解・損失・勾配を必要としない。学習の説明で初めて正解を登場させる。
- 各コマで一つの意味のある計算を強調し、「どの値を使い、何を計算し、何が得られたか」を一文と代入式で示す。数値・式は点滅させない。
- 代表ニューロンと経路は説明順に固定し、ステップに合わせて強調する。任意のニューロン・辺を選ばせる操作は設けず、ホバーだけに説明を置かない。
- 順伝播の値と逆伝播の勾配は別欄に表示する。色に加え、矢印の向き・線種・「値」「勾配」の文字でも区別する。
- ステップを戻すと、その時点の値・勾配・式・説明がすべて戻る。戻る操作は記録した履歴の参照で、更新を逆に実行しない。
- 入力・重み・学習率の自由編集、ReLUの切り替え、任意の再学習は置かない。固定した説明例の計算を読み進めるために操作を使う。

## 順伝播の数値例

xは列ベクトル。上付きの(1)・(2)は隠れ層の番号、下付きはニューロンや入力の番号である。Wの行は行き先、列は入力元と説明し、図に寸法を添える。以下は制作側の数値一覧であり、本文ではPythonコードとして読ませず、数式と図の該当箇所に値を表示する。

```text
x = [1, 2]ᵀ                    y = 2
W¹ = [[1, 0.5], [0.5, 0.5], [-1, 0.5]]    b¹ = [0, -0.5, 1]ᵀ
W² = [[0.5, 0.5, 0.5], [0.5, 0.5, 1], [-0.5, 0, 0.5]]
b² = [-0.5, -2, 1.5]ᵀ
v = [0.5, 0.5, 0.5]ᵀ            c = 0
z¹ = W¹x + b¹ = [2, 1, 1]ᵀ
h¹ = ReLU(z¹) = [2, 1, 1]ᵀ
z² = W²h¹ + b² = [1.5, 0.5, 1]ᵀ
h² = ReLU(z²) = [1.5, 0.5, 1]ᵀ
ŷ = vᵀh² + c = 1.5
L = (1/2)(ŷ − y)² = 0.125
```

入力x₁=1と予測ŷ=1.5を異なる値にし、入力がそのまま出力されたように見えない例とする。動く例では更新前後の隠れ層をすべて正の値にし、値・勾配が0で途切れない計算を追う。ReLUの負側は静止図と数式で説明する。

寸法は `x:2×1、W¹:3×2、b¹・z¹・h¹:3×1、W²:3×3、b²・z²・h²・v:3×1`、c・ŷ・Lはスカラーとする。

まず全体図と、第一隠れ層の第一ニューロンの `z¹₁ = 1×1 + 0.5×2 + 0 = 2`、`h¹₁ = max(0,2) = 2` を説明する。再生は入力→第一隠れ層の3個の重み付き和とReLU→第二隠れ層の3個の重み付き和とReLU→出力の重み付き和→予測の順。一つのニューロンの積・和・活性化を詳しく見せ、同じ計算の繰り返しは数値を残しながら簡潔に進める。

重みは辺のラベル、バイアスは加算する独立の値として表示する。推論中は重みを固定し、中間値と予測を計算する。手設定の初期重みと、画像認識の比較で使う学習済み重みを区別する。入力を変える課題は設けない。

## 損失・連鎖律・逆伝播のステップ

予測ŷ=1.5に対して正解y=2を示し、損失0.125を計算する。続けて「この重みを少し変えると、損失はどれだけ変わるか」から連鎖律へ進む。

代表経路は `L→ŷ→h²₁→z²₁→h¹₁→z¹₁→W¹₁₁`。文章・式・拡大図で局所微分の積を説明し、再生で各因子と経路を対応付ける。この経路からの寄与は `(-0.5)×0.5×1×0.5×1×1 = -0.125`。これだけがW¹₁₁の勾配ではなく、第二隠れ層の他のニューロンを通る経路もあることを全体図で示す。

`g_h¹ = ∂L/∂h¹`、`δ¹ = ∂L/∂z¹`、`δ² = ∂L/∂z²` と記号を定義する。局所微分と、その場所へ戻ってきた勾配を別に表示し、掛け算と複数経路の加算を区別する。

| 段階 | 初期例で表示する計算 | 説明する意味 |
|---|---|---|
| 損失から出力 | `∂L/∂ŷ = ŷ − y = −0.5` | 予測を少し増やすと、この地点では損失が減る |
| 出力の重み・バイアス | `∂L/∂v = [−0.75, −0.25, −0.5]ᵀ`、`∂L/∂c = −0.5` | 上流勾配に各入力h²を掛ける。バイアスの局所微分は1 |
| 第二隠れ層の出力・ReLU | `∂L/∂h² = [−0.25, −0.25, −0.25]ᵀ`、`ReLU′(z²) = [1, 1, 1]ᵀ`、`δ² = [−0.25, −0.25, −0.25]ᵀ` | 順伝播時のvを使う。この入力ではReLUの局所微分はすべて1 |
| 第二隠れ層の重み・バイアス | `∂L/∂W² = δ²(h¹)ᵀ = [[−0.5, −0.25, −0.25], [−0.5, −0.25, −0.25], [−0.5, −0.25, −0.25]]`、`∂L/∂b² = δ²` | 第一隠れ層の順伝播時の値を使う。重みはまだ変更しない |
| 第一隠れ層へ戻る寄与の加算 | `g_h¹ = (W²)ᵀδ² = [−0.125, −0.25, −0.5]ᵀ` | 同じ値が複数経路で使われたら、戻ってくる寄与を足す |
| 第一隠れ層のReLU | `ReLU′(z¹) = [1, 1, 1]ᵀ`、`δ¹ = [−0.125, −0.25, −0.5]ᵀ` | 合計した勾配に局所微分を掛ける |
| 入力側の重み・バイアス | `∂L/∂W¹ = δ¹xᵀ = [[−0.125, −0.25], [−0.25, −0.5], [−0.5, −1]]`、`∂L/∂b¹ = δ¹` | 入力xを掛け、全パラメータの勾配が揃う |

分岐の説明では `∂L/∂h¹₁ = (−0.25)×0.5 + (−0.25)×0.5 + (−0.25)×(−0.5) = −0.125` を図の3経路と対応付ける。3経路からの寄与−0.125、−0.125、＋0.125を足し、`∂L/∂W¹₁₁ = −0.125×1×1 = −0.125` になると説明する。この例では第二・第三経路の寄与が打ち消し合うが、全経路の寄与を計算する必要がある。分岐の加算を入力の微分だけで説明せず、更新する重みの勾配に結び付ける。

「誤差の値をそのまま逆に流す」のではなく、損失の各値に対する微分を伝えると説明する。入力自体は更新しない。ReLUの0での微分は通常の意味では定まらないため、教材の計算では0を採用する規約を添える。初期例と更新後の例は折れ点を避け、勾配の数値検証も折れ点以外で行う。

## 更新と再推論：更新前後を横並びで比較する

すべての勾配が揃ってから `θ_new = θ_old − η∇L` を一回適用する。更新前の重み・勾配・更新量・更新後の重みを表で示す。逆伝播中に重みを書き換えず、全パラメータを同じ更新前の値から更新する。

固定した学習率η=0.05での更新後の値は次とする。

```text
W¹_new = [[1.00625, 0.5125], [0.5125, 0.525], [-0.975, 0.55]]
b¹_new = [0.00625, -0.4875, 1.025]ᵀ
W²_new = [[0.525, 0.5125, 0.5125], [0.525, 0.5125, 1.0125], [-0.475, 0.0125, 0.5125]]
b²_new = [-0.4875, -1.9875, 1.5125]ᵀ
v_new = [0.5375, 0.5125, 0.525]ᵀ       c_new = 0.025
```

**左に更新前、右に更新後を常時並べる。** 両側の図の配置・数値の表示精度・入力・正解を揃える。左側は計算済みの状態で固定し、右側は更新後の重みを表示して、中間値と予測の数値欄を空欄から順に埋めて計算し直す。一つのプレイヤーで右側の順伝播を進め、各コマで左側の対応箇所も強調する。切り替え表示や、古い値が消える表示にはしない。狭い画面では左右比較を読める幅で保持し、必要なら比較領域を横スクロールできるようにする。

| 表示する値 | 左：更新前 | 右：更新後 |
|---|---|---|
| 入力x・正解y | `[1, 2]ᵀ`・2 | 同じ値 |
| 第一隠れ層のz¹ | `[2, 1, 1]ᵀ` | `[2.0375, 1.075, 1.15]ᵀ` |
| 第一隠れ層のh¹ | `[2, 1, 1]ᵀ` | `[2.0375, 1.075, 1.15]ᵀ` |
| 第二隠れ層のz² | `[1.5, 0.5, 1]ᵀ` | `[1.7225, 0.7975, 1.1475]ᵀ` |
| 第二隠れ層のh² | `[1.5, 0.5, 1]ᵀ` | `[1.7225, 0.7975, 1.1475]ᵀ` |
| 予測ŷ | 1.5 | 1.962 |
| 損失L | 0.125 | 0.000722 |

「重みが変わる→中間値が変わる→予測と損失が変わる」を見比べる。例えば右側の出力は `0.5375×1.7225 + 0.5125×0.7975 + 0.525×1.1475 + 0.025 = 1.962`。古い中間値を使い回さない。更新後は正解2に近づき、差の絶対値は0.5から0.038になって損失が減ったと説明する。この一例で損失が減ったことと、任意の学習率で必ず減るという主張を区別する。学習率の自由変更や連続学習の追加操作は設けない。

計算プレイヤーはこの小例をCPUで計算し、保存した履歴から表示する。実装ではmarimoの`mo.iframe`に自己完結した再生部品を埋め込み、ブラウザ内で履歴の表示位置だけを動かす。戻る・再生し直す操作でも更新を二重適用しない。初期値・勾配・更新後の値を一つの計算条件として管理する。

## 表現力・学習・汎化と05への接続

複雑な関係を表せることは表現力、訓練データに対して損失を減らすことはパラメータの学習、学習に使わなかったデータでも予測が通用することは汎化として分けて説明する。手書き数字の数枚の予測例や一サンプルの更新結果だけで、NNの汎化性能が高いとは結論付けない。

NNでも未知データでの評価が必要と短く確認し、モデルを大きくすることや更新回数を増やすことだけで性能は保証されないと説明する。05で手書き数字の認識に戻り、MNISTのMLP、Autograd、optimizer、学習曲線・過学習・正則化を実際の学習と評価につなげる。04では評価実験を追加して仕組みの説明を圧迫せず、代表図と短い文章で位置付ける。
