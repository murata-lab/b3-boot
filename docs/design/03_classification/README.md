## 文章と数値例

線形二値分類は `s=wᵀx+b`、`p=sigmoid(s)`、p≥0.5でクラス1という順に説明する。x=1、w=−1、b=0ならp≈0.269で予測0。正解1と比較して、重みを増やす意味を示す。正解ラベルは予測の入力に含めない。

二特徴量の境界は、w₁=1、w₂=−1、b=0の直線と4点の固定図だけにする。選択点・背景の確率メッシュ・訓練と検証のダッシュボードは置かない。

尤度は観測データを固定した重みの関数として説明する。重み自体の確率とはしない。正解への確率qᵢはyᵢ=1ならpᵢ、yᵢ=0なら1−pᵢ。ラベルの条件付き独立を仮定して積を取り、最尤推定へ進む。二点への確率[0.8,0.6]と[0.9,0.7]の尤度0.48・0.63を比較する。

対数の単調性、積から和、符号反転、平均という順に交差エントロピーを導く。一点の損失ℓᵢ=−log qᵢと全体の平均Lを区別する。q=0.2・0.5・0.8の損失は約1.609・0.693・0.223。確率の操作欄は置かない。

## 共通データ

微分以降は、x=[−3,−2,−1,1,2,3]、y=[0,1,0,1,0,1]の6点を使う。一境界で完全に分離できない配置を選び、有限の谷を持つ損失を描く。初期値は(w,b)=(−1,0)、損失は平均二値交差エントロピー。数値は内部で丸めず、本文と表示は主に小数3桁とする。

sigmoidと交差エントロピーはスコアから安定に計算する。多クラスのsoftmaxは最大スコアを引いて計算する。Pythonの数値計算・本文・静止図は `03-classification/notebook.py` に集約し、補助Pythonファイルは作らない。

## 動く図：勾配降下法だけ

目的は「同じ更新式を繰り返すと、重みが動き、傾きが小さくなっていく」ことの観察。横軸w・縦軸Lの一つの損失曲線に、現在の点・それまでの移動・現在の傾きを重ねる。バイアスは0固定、学習率0.3。初期w=−1、L≈1.496、微分≈−1.117から、初回更新w≈−0.665、L≈1.146へ進む。

- 初期状態＋9回の更新、合計10状態。一回進むと必ず重みが一回更新される。
- 操作は「戻る」「進む」「ループ再生」の3ボタン。再生ボタンは再生中に「一時停止」へ変わる。
- 初期状態は停止。再生中は1.6秒ごとに一更新し、末尾から初期状態へ戻って繰り返す。
- 前後操作で自動再生を停止する。先頭の戻る・末尾の進むは無効。停止後の古い通知は無視する。
- 表示する値は更新回数・現在のw・Lの一行。速度・位置スライダー・先頭・リセット・詳細モードは設けない。
- 予測、損失、微分、更新量を別々のコマに分割しない。更新式の意味と数値代入は、図の前の本文で説明する。

## 学習率の静止図

共通6点、初期値、b=0固定、バッチ勾配降下法、9更新という条件をそろえ、η=0.1・1・3の損失を横並びにする。軸の範囲も共通にする。0.1はゆっくり低下、1はこの例で素早く低下、3は谷を飛び越え損失が上下する。η=3では初回の損失が約1.496から1.601へ増える。

## 三手法の静止図

wとbの両方を更新し、横軸w・縦軸bで三つの移動軌跡を並べる。バッチは青の実線、ミニバッチは橙の破線、SGDは紫の点線。○を共通の初期値、●を6エポック後とし、軸の範囲も共通にする。

条件は学習率0.3、NumPy default_rng(31)、各エポックのシャッフルを共通にする。全6点・2点・1点から平均勾配を計算し、6エポックでそれぞれ6・18・36回更新する。バッチの直線、ミニバッチの曲がり、SGDの細かい揺れを本文と対応付ける。

このデータでは対称性からバッチのbが動かないため直線になると説明する。どのデータでも直線になるとはしない。部分集合の勾配による揺れ、全データの損失が毎回下がるとは限らないこと、SGDがミニバッチを含む呼称にもなることを述べる。図の終点だけで速度・性能を順位づけない。
