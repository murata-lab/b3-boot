## ライブラリを使う説明

まず標準ライブラリの短い例で `import` を説明する。その後、グラフを描くためにMatplotlibを追加する。説明と短い完成例に絞り、描画APIの講義や保存・比較の演習は作らない。

追加操作は別のターミナルを開き、教材ルートで `uv add matplotlib` を実行する。起動用ターミナルでmarimoを終了し、同じ起動コマンドで再開してこの節へ戻る。操作場所・目的・期待する結果をその場に明記する。

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots()
ax.plot([1, 2, 3], [2, 4, 6], marker='o')
fig
```

`fig, ax` が二つの戻り値を受け取ること、`as plt` が別名を付けること、`ax.plot(...)` が描画の処理を呼ぶことを、そのコードのそばで説明する。3点を結ぶ線を出力として示す。

`uv add` と `import` の違いはここで説明する。`uv add matplotlib` はターミナルでプロジェクトの依存関係に追加する操作、`import matplotlib.pyplot as plt` はPythonコードでモジュールを読み込み名前を使えるようにする操作である。標準ライブラリはPythonに付属するので `uv add` は不要。追加済みのライブラリでも、使うコード側では読み込みが必要になる。

未導入のMatplotlibが01の初回表示を妨げないようにする。未導入時は描画セルを止めて追加手順を表示し、先にimportエラーや自動インストール要求を出さないことを実装時に確認する。
