# 01 Python入門

短いPythonコードを読み、値を変えて実行するための基本と、NumPy配列の計算・形（shape）を学びます。本文・コード・出力は [notebook.py](notebook.py) にあります。

## 開き方

[環境の準備](../SETUP.md)を済ませ、ターミナルで教材のルート（`README.md` と `SETUP.md` がある `ml-bootcamp` フォルダ）へ移動します。`01-python` の中では実行しません。

```sh
uv run python app.py
```

教材一覧、または左上の **☰** メニューから「01 Python入門」を選びます。すでに入口を開いている場合は、サイドバーで章を選ぶだけです。

ブラウザに本文とコードが表示されます。コードを変更したら、セルの右上の ▶ を押して実行します（`Ctrl+Enter`、Macでは `⌘+Enter` でも実行できます）。終了は起動したターミナルで `Ctrl+C`、再開は同じ場所で同じコマンドです。

11節のPythonファイルを試すときは、別のターミナルを開き、教材ルートから実行します。

```sh
uv run python 01-python/hello.py
```

そのターミナルに `Hello, world!` と `5` が1行ずつ表示されます。
