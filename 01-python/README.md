# 01 Python入門

短いPythonコードを読み、値を変えて実行するための基本を学びます。本文・コード・出力はすべて [notebook.py](notebook.py) にあります。読む時間の目安は10〜20分です（環境準備を除く）。

## 開き方

[環境の準備](../SETUP.md)を済ませ、ターミナルで教材のルート（`README.md` と `SETUP.md` がある `b3-ml-bootcamp` フォルダ）へ移動します。`01-python` の中では実行しません。

```sh
uv run python app.py
```

教材一覧、または左上の **☰** メニューから「01 Python入門」を選びます。すでに入口を開いている場合は、サイドバーで章を選ぶだけです。

ブラウザに本文とコードが表示されます。コードを変更したら、そのセルを `Shift+Enter` で実行します。終了は起動したターミナルで `Ctrl+C`、再開は同じ場所で同じコマンドです。

ターミナルからPythonを直接実行する例は、別のターミナルを開き、教材ルートから実行します。

```sh
uv run python -c "print('Hello, world!')"
```

そのターミナルに `Hello, world!` と表示されます。
